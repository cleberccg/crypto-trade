# Timeline

The Execution Timeline records the platform history as a chronological event stream.

## Stored Events
- Download iniciado
- Download concluído
- Optimizer iniciado
- Checkpoint salvo
- Novo melhor PF
- Validation iniciada
- Validation concluída
- Backup criado
- Research atualizado
- Paper Trading iniciado
- Live Trading iniciado

## Current State
- Read-only mock timeline is available.
- API endpoint: `/api/v1/timeline`.
- Dashboard page: `Execution Timeline`.
